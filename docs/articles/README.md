way they do. They use concrete failure modes and design trade-offs rather than
serving as command references.

  separates the worker, watchdog, verifier, and host-owned authority.
- [What Survives the Window](adaptive-context.md) — why useful history needs
  governed persistence, retrieval, and learning rather than a larger prompt.
